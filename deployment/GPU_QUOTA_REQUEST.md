# GCP billing and GPU quota: what to request (instructions for the account owner)

Nothing has been filed. Requests cost nothing, but approval can take days; file near the end of Phase A.
Verify the exact names in the console (IAM & Admin > Quotas) because Google renames SKUs.

## Billing prerequisites
1. A Google Cloud billing account that is a **paid (upgraded) account**, not the free trial. GPU quota is normally refused on trial accounts.
2. Currency INR; payment method valid for Indian recurring payments (RBI e-mandate rules may require card re-authorization or prepayment).
3. A **new project dedicated to training** (e.g. `agentic-banker-train`) linked to that billing account. Record the project ID in `deploy/gcp/env.sh`.
4. You hold Billing Account Administrator and Project Owner; Organization policies must allow external-IP-free instances and Cloud NAT.
5. Do not enable any hosted model API in this project.

## Quota requests (region `asia-south1`, Mumbai)
Request each as an *increase* on the new project, with a plain use-case line (the AWS case failed with an autogenerated line).

| Quota (console name) | Region | Value |
|---|---|---|
| Preemptible A100 80GB GPUs (`PREEMPTIBLE_NVIDIA_A100_80GB_GPUS`) | asia-south1 | 1 |
| Preemptible NVIDIA A100 GPUs (`PREEMPTIBLE_NVIDIA_A100_GPUS`, 40GB fallback) | asia-south1 | 1 |
| GPUs (all regions) (`GPUS_ALL_REGIONS`) | global | 1 (ask for 2 if a fallback may be tried while the first is still stopping) |
| CPUs (`CPUS`), and Preemptible CPUs (`PREEMPTIBLE_CPUS`) | asia-south1 | 16 (a2-ultragpu-1g has 12 vCPUs) |
| Persistent Disk SSD/Balanced (GB) | asia-south1 | 500 |
| In-use IP addresses | asia-south1 | default is fine (the GPU VM has none) |

Spot VMs use the *Preemptible* GPU quota names. If the console shows `Spot`/`Preemptible` wording differently, request the entry that matches `a2-ultragpu-1g` spot in asia-south1.

## Suggested use-case text
"Self-hosted fine-tuning and evaluation of open-weight language models on a single A100 80GB spot VM, about 110 GPU-hours per month, private VPC, no public IP, data in an India bucket. No resale and no external user traffic."

## Before you start any VM
- Re-verify the hourly price in the GCP pricing calculator and update `deploy/gcp/gpu_rates.json`.
- Confirm a zone in asia-south1 actually has A100 80GB spot capacity (quota is not capacity; a start can still fail).
- Fill and approve `deployment/GPU_RUN_PLAN_TEMPLATE.md`.
- Create the budget and kill switch (`deploy/gcp/05_budget_kill_switch.sh`) and test it first.
