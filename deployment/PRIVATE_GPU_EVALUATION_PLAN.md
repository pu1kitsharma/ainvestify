## Purpose and acceptance

Evaluate whether a stronger **self-hosted** model can make source-bound Indian
seed-investment decisions more reliably than the installed local qwen3:14b. The
first case is the existing public-only QOSMIC evidence set. A model that is
faster yet still confuses an announced funding event with confirmed cash, a
planned deployment with current capacity, or a company claim with independent
verification fails. A successful reasoning benchmark is necessary but cannot
replace calculation checks, exported-file inspection or investment review.

Pin the exact public source versions and model weights/quantization, use the
same held-out claim/recommendation tasks for both models, preserve every raw
response and latency/usage record, and have deterministic validators plus an
independent review of the model-authored answer. Do not feed a manually written
recommendation to the model. Measure unsupported assertions, temporal errors,
numeric drift, abstentions, correction count and task completion within the
existing bounded pass. Promote no memo/PDF with an unresolved material defect.
Private company uploads stay on the Mac during this public-only benchmark. Cloud
private-document qualification requires separate egress, identity, encryption,
retention and deletion checks.

## Cost envelope

AWS's public EC2 price list checked on 2 October 2026 listed Linux on-demand
`g6e.2xlarge` at **US$2.69266/hour** in both regions and gp3 at
**US$0.09120/GB-month**. These are usage prices, not a fixed quote. At a
deliberately conservative **planning conversion of ₹100/US$** and an assumed
**18% tax**, the monthly allocation is:

| Item | Cap / calculation | Estimated INR |
| --- | ---: | ---: |
| GPU running time | 32 hours × $2.69266 | ₹8,617 |
| 100 GB gp3 volume | 100 × $0.09120 | ₹912 |
| Assumed 18% tax on above | ($86.16512 + $9.12) × 18% × ₹100 | ₹1,715 |
| **Subtotal** | | **₹11,244** |
| **Reserve** | network, public IPv4, snapshots, FX, pricing drift | **₹3,756** |

The 32-hour cap is a maximum, not an expected run. Start with a four-hour
public-only canary (~₹1,271 compute and assumed tax at this planning rate),
inspect results, and stop. Do not start a second run if committed usage and
worst-case remaining charges could breach ₹15,000. Verify live price, taxes,
FX and all attached-resource charges in the account before provisioning.
AWS Budgets is an alert/secondary stop mechanism; billing data can lag and is
not a hard spending limit. The US$100 account-wide alert is configured, but
an explicit instance run deadline, a separate scheduled stop action, and a
manual stop check still need implementation and verification. Keep the EBS
volume encrypted and accounted for while the instance is stopped. Do not use
Spot for the first reproducibility run.

## Launch and rollback sequence

1. Obtain approval after an appeal of the denied G/VT quota request (8 vCPUs for
   `g6e.2xlarge`). Establish a separately scoped non-root provisioning role;
   the verified SSO role is read-only. Verify Cost Explorer visibility, the
   budget's email delivery and a hard stop deadline. Verify billing currency/tax,
   zone-level capacity, service limits and the current region price.
2. Create a narrow evaluation role/security group: no public model endpoint,
   SSH only through an authenticated management path, encryption at rest,
   logs without source text, and outbound access only for approved setup and
   model acquisition. Do not upload the local SQLite DB, ES index, originals,
   credentials, Toffee files or other room data.
3. Pin and review the model artifact and serving stack. Record hashes. Configure
   the existing local inference interface against this private endpoint only
   for an isolated evaluation; prohibit any hosted LLM fallback.
4. Run the public-only QOSMIC held-out tasks. Retain responses and validator
   reports in the protected local experiment store. Cross-check actual answer
   content, not only schema compliance or model agreement.
5. Stop the instance at the deadline and confirm stopped state. Retain or remove
   the encrypted EBS volume based on the recorded evidence-retention need and
   its ongoing cost; delete any unused IP/snapshot. Verify final charges.

Passing this canary would permit further evaluation, not an investment
recommendation, investor-ready artifact, or multi-user release.
