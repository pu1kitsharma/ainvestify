# Local reviewer interface capability

One frozen four-example factual-review call on the installed phi4-mini model, at most 45 seconds / one logical and HTTP request. Exact input and final output are retained. Includes two valid proposed/attributed drafts and two actual unsupported assertions. Required verdicts: pass, pass, revise, revise. No production company, reference answer or live data is modified. This tests whether the critic distinguishes proposed work and attribution from false claims before another full workflow. Not a model-size sweep or a general accuracy benchmark.
