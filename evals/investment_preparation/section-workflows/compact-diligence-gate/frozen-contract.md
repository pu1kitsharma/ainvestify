# Compact diligence gate: frozen before inference

One case: the five complete, curated source-checked paraphrases in `paasa-reference-input.json`. This isolates reasoning from collection and extraction and is not an unseen-case or end-to-end evaluation. No reference answer is passed to the model.

One local Qwen3.5:9b nonthinking call, context 8192, at most 2000 generated tokens, 60-second total capability budget, one HTTP request, no correction or retry. Record whether a model was loaded before the call. Do not preload or download.

Acceptance requires two distinct company-specific plans (unit economics first), with useful underlying records, a question those records and calculation can actually resolve, correct entity/service/population/period scope, economically meaningful operands, preserved source qualifications, and no fabricated performance. Assets are not revenue. Partner charges cannot be deducted twice. Cohort rates need compatible eligibility and observation windows; behavior alone does not establish churn causes. Missing data leave decisions unresolved. Schema validation is necessary but is not a content acceptance decision.

After the call, independently inspect raw and expanded outputs and derived actions. If this core task passes, implement a smaller shared-analysis workflow, then separately prove a complete pack within 120 seconds. If it fails, record the failure and stop automatic inference attempts. This gate cannot promote a production model or prove MVP readiness.
